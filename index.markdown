# Advanced Repair Console (ARC-PE)

### Welcome!  This site showcases the Advanced Repair Console capstone project.

The ARC application is a unique tool designed to bridge the gap between knowledge and execution.  Often, technicians lack software repair experience and in a repair environment, finding time to educate techs on a field with such nuance (software repairs) is not always possible.  This tool aims to help technicians automatically complete software repairs without any intervention by the tech.  The goal is a set it and forget it tool that tells the technician exactly what went wrong so they may effectively communicate that with the client while establishing a baseline software repair competence across multiple stores.  In the day to day often technicians in other locations will send clients to ours due to my software repair competencies, this tool means the easy problems are solved which makes up a vast majority of client OS repairs.
